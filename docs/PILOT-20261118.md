- 先定输入输出和核心承诺，再看测试；全绿只覆盖已写期望。
- 未知不伪零；分开材料数、独立来源数、已核实体数；候选目标不是批准与市场事实。

- 验证器要负控、类型边界、缺文件失败关闭；不要继续维护脆弱自造框架。
- 过去先冻结旧包再判断价值，让历史约束阻止淘汰；本次先判价值，用固定Git恢复点替代当前树堆积。
